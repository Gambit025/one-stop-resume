# 三轮交付记录

## 基线与约束

- 基于改版前线上 `/`，一次真实请求返回 200，首字节 41.817 秒、总计 41.877 秒。此数包含可能的免费实例唤醒和公网传输，不能当作页面 LCP。
- 同一轮已唤醒服务的虚构英文样本转换为 11.237 秒（单样本，不代表中文中位数或 P90）。
- 原服务同步生成、单线程、模拟阶段、固定单页预览。新增队列最多一个运行、两个等待，120 秒期限包含等待。
- 测试只用自动生成的虚构内容；不对用户文件做测量。性能目标是优化目标而非付费 SLA。

## 第一轮

- 子进程执行转换，超时或删除可终止整个进程组；HTTP 查询与独立 `/health` 不被 AI 调用占用。
- 校验实际 PDF、大小、页数、加密、可提取文本与字符上限。任务凭证仅以 SHA-256 校验值保存在内存。
- 真实阶段、每阶段耗时、字符/数字核对、受保护的逐页 PNG 预览与 PDF 下载；不写入内容日志。
- 一小时到期、五分钟清理，完成即移除原始输入和 HTML；部署重启后凭证失效。保留结果仅位于临时磁盘。
- 固定部署依赖；一进程四 HTTP 线程，最多一个转换子进程。第一轮暂时提供旧页面兼容接口，第二轮移除。
- 9 项本地测试通过：正常样本、损坏/加密/扫描/超页/超字/超大小、凭证、队列、健康检查、超时、删除与到期、结构及内容差异。
- 第一轮线上冒烟通过：虚构中文简历 32.996 秒，读取 0.893 秒、AI 1.824 秒、渲染/预览 19.670 秒；PDF 与预览可下载，无凭证访问被拒绝，测试文件删除成功。该输入与旧英文基线不同，不能据此声称加速。

## 第二轮

- 新原生前端采用上传、内置/自定义模板、真实任务阶段、内容差异提示、凭证会话恢复、独立下载与立即删除。
- 逐页 PNG 直接来自最终 PDF，避免旧 iframe 隐藏布局测量产生 0% 缩放；ResizeObserver 根据可用宽度重新适配所有页。
- 删除旧 `/api/generate` 和无凭证预览兼容接口。失败不清空已选文件，提交不自动重试以防重复计费。
- 本地使用隔离的确定性 AI 替身与真实 Chromium 渲染验证：文件上传、默认模板、生成、内容核对、下载不跳页、刷新恢复、立即删除均通过。
- 本地与线上测试入口均位于 tests，不会复制进入生产镜像。私人 PDF、.env 和嵌套仓库均未加入提交。
- 第二轮线上混排样本 34.319 秒，下载/预览/删除验证通过；内容检查发现 AI 遗漏部分混排文字，触发核对警告，没有误报为无损成功。第三轮针对该缺陷增加一次严格逐行核对重试，仍有差异时保留警告。

## 第三轮

- 暖白纸张工作台、系统字体、原生控件、清晰焦点与低动态偏好；移除星空、光效、虚构进度及不实宣传。
- 旧大预览使用的 PNG 只有半页高；现从公开模板 PDF 生成完整 WebP 预览和独立小缩略图，避免裁切，减少模板列表传输。
- 390 / 768 / 1440 宽度检查与一次集中修复后的确认均无页面横向溢出。两页 PDF 的两张预览可滚动查看，缩放读数均大于 0，下载与刷新恢复通过。
- 增加字符、词句片段、数字核对；发现差异时至多一次严格结构化重试，采用差异更少的候选；无法修复时明确提示并要求勾选后下载，不静默丢弃信息。
- PDF 与 PNG 渲染耗时分开记录，预览栅格降到 1.1 倍以降低免费 CPU 的负担。读取/结构化/渲染仅记录阶段耗时、页数与是否有警告。
- 15 项自动化测试覆盖格式、资源边界、队列、进程异常、超时、删除/过期/重启、凭证、内容差异、免费额度/认证/网络异常与输出截断。
- 声明的正文、次要文字、主按钮、警告、错误和成功文字角色已计算对比度，均高于 4.5:1；这不是对整站的第三方 WCAG 认证。
